หัวข้อที่เรียน
-Git พื้นฐาน

สิ่งที่ได้
git --version  //ตรวจสอบว่า Git ติดตั้งอยู่หรือไม่ถ้าติดตั้งแล้วจะแสดงเวอร์ชัน
git init  //สร้างโฟลเดอร์ .git ทำให้โฟลเดอร์นี้เป็นโปรเจกต์ Git
git status  //ดูว่าไฟล์ไหนถูกแก้ไขไฟล์ไหนยังไม่ได้เพิ่มไฟล์ไหนพร้อม Commit
git add .  //เตรียมไฟล์สำหรับ Commit . หมายถึงทุกไฟล์ในโฟลเดอร์
git commit -m "First Commit"  //บันทึกการเปลี่ยนแปลง "First Commit" คือข้อความอธิบาย
git remote add origin ลิ้งของเรา  //เชื่อมโปรเจกต์ในเครื่องกับ Repository บน GitHuborigin เป็นชื่อของ Remote
git branch -M main  //เปลี่ยนชื่อ Branch หลักเป็น main
git push -u origin main  //อัปโหลดขึ้น GitHub -u ทำให้ครั้งต่อไปใช้แค่
